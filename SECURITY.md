# Security policy

Waleed MCP Hub stores MCP credentials on your machine (Windows DPAPI) and edits AI
agent config files. Security reports are welcome.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** button on the repository's Security tab
(private vulnerability reporting). Please do not open a public issue for a
security problem.

Include the version or commit, the steps to reproduce, and what an attacker could
gain. Never include real credentials in a report.

## Supported versions

Only the latest commit on `main` receives fixes.
