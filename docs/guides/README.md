# Waleed MCP Hub guides

Practical how-tos for using the hub. For the design and safety model, see the
[specification](../SPECIFICATION.md) and [decisions](../DECISIONS.md).

Open **Help & Guides** in the app header to search these bundled sources offline.
The first-run tour is available again from **Settings → Re-run Onboarding**.

- [Add any MCP server](adding-mcps.md): remote HTTP/SSE, API keys, OAuth, npm and
  Python packages, native executables, Docker images, and pasting existing configs.
- [Connect your AI agents](connecting-agents.md): Claude Desktop, Claude Code, Codex,
  OpenCode, VS Code, Cursor, Antigravity, Kimi and Kilo, where each config lives,
  and how to reconnect.
- [Troubleshooting](troubleshooting.md): white window, approval and auth errors,
  exit code -1, Needs Re-auth badges, and agents that show no tools.
- [Security & Privacy](security-privacy.md): DPAPI, JobObject containment, loopback
  isolation, setup confidentiality and private backup boundaries.
- [Roadmap](../ROADMAP.md): what's planned and how it compares with similar projects.
